Code & prompts — l'itération

Dire pour qui écrire ne suffit pas

Version 1

Audience: a non-technical manager

Le modèle produit exactement le même texte pour les deux audiences.

Version 2

Use plain business language.
Ban technical jargon entirely.
Emphasise impact, deadlines and risk.

On ne nomme plus le lecteur : on décrit l'opération à effectuer sur le texte.

Même mesure des deux côtés : le recouvrement de vocabulaire entre les deux versions passe de 100 % à 24 %.

Voici notre itération de prompt, et c'est le passage à retenir sur la partie prompt engineering. En version 1, on écrit simplement « Audience : un manager non technique ». C'est ce que faisait le sujet. Résultat : le modèle produit strictement le même texte pour un manager et pour un ingénieur. La consigne est décorative. En version 2, on arrête de nommer le lecteur et on décrit l'opération : utilise un langage métier simple, bannis le jargon, insiste sur l'impact et les délais. Là, le texte change vraiment. Le point de méthode est qu'on a mesuré la même chose avant et après — le recouvrement de vocabulaire entre les deux versions. On passe de 100 % à 24 %. Sans cette mesure identique des deux côtés, on aurait juste une impression.
