Le code de départ régénérait les résumés à chaque étape : chaque contrôle évaluait donc un texte différent de celui qu'on venait de juger. Une génération unique rend l'évaluation cohérente et reproductible.

Voici l'architecture. Un prompt, huit résumés générés une seule fois, puis trois contrôles indépendants. Le détail qui compte est la génération unique. Le code fourni au départ rappelait la fonction de résumé à chaque section : le contrôle de longueur évaluait un texte, le juge en évaluait un autre, la comparaison d'audience un troisième. Les chiffres n'étaient donc pas comparables entre eux. On génère une fois, à température zéro, et tous les contrôles portent sur le même corpus. C'est la condition pour que les résultats soient reproductibles — si on relance le notebook, on obtient les mêmes chiffres.
