Code & prompts — le prompt principal

Un contrat de format, écrit pour être vérifiable

Summarize the meeting transcript below.

Audience: {audience}
Hard limits:
- At most {max_words} words in total.
- Exactly 3 bullet points, each starting with "- ".
- Then a line containing exactly "Actions:"
  followed by one line per action item.

Return nothing else: no preamble, no title.

Chaque règle est testable

« Exactly 3 bullet points » se vérifie en comptant les lignes. « Actions: » se cherche dans le texte.

Interdire explicitement

« Return nothing else » supprime les préambules du type « Voici le résumé : ».

Voici le prompt principal, tel qu'il est dans le code. Le point de méthode : chaque contrainte est formulée pour être vérifiable par un programme. « Exactly 3 bullet points, each starting with dash » se contrôle en comptant les lignes qui commencent par un tiret. « A line containing exactly Actions » se cherche dans la chaîne. On ne demande jamais quelque chose qu'on ne saura pas mesurer. Deuxième point : la dernière ligne, « Return nothing else ». Sans elle, un petit modèle ajoute systématiquement « Voici le résumé que vous avez demandé ». Ça casse le parsing. Le prompt de départ demandait bien 3 bullets, mais rien ne vérifiait que le modèle obéissait.
