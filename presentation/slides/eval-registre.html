Les deux dernières mesures, rapidement. À gauche, l'effet de l'audience, déjà évoqué. Le recouvrement de vocabulaire entre la version manager et la version ingénieur passe de 100 % à 24 % entre nos deux prompts. C'est notre itération la plus rentable. À droite, le rappel des décisions : 94 % des action items de référence sont retrouvés dans les résumés produits. Un seul document tombe à 50 %. Une précision honnête sur cette mesure : elle est lexicale, pas sémantique. On compare les mots. Si le modèle reformule correctement sans réutiliser les mêmes termes, on compte un échec. Donc 94 % est probablement un plancher, pas un plafond. À noter : c'est notre seule mesure entièrement objective, sans annotation humaine ni jugement de modèle.
